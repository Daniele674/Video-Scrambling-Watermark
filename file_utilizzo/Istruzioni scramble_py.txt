**ISTRUZIONI PER L'USO**

### 1. Modalità di utilizzo

Installare librerie esterne tramite il comando:
```
pip install -r requirements.txt
```

Per eseguire lo script, aprire un terminale e utilizzare il comando:

```
python scramble.py [opzioni]
```

### 2. Parametri a riga di comando

Lo script accetta i seguenti parametri:

- **-k, --key**  
  *Descrizione*: Chiave di cifratura.  
  *Dettagli*: Deve essere una stringa la cui codifica in bytes abbia una lunghezza valida (16 bytes).  
  *Default*: `b'supersegreto1236'`

- **-t, --scramble_type**  
  *Descrizione*: Tipo di scrambling da applicare.  
  *Dettagli*: Può essere:
  - `permutation`: applica una permutazione dei coefficienti.
  - `signFlip`: modifica i segni di alcuni coefficienti (richiede il parametro `num_to_flip`).
  *Default*: `permutation`

- **-n, --num_to_flip**  
  *Descrizione*: Numero di coefficienti da modificare.  
  *Dettagli*: Utilizzato solo se il tipo di scrambling scelto è `signFlip`.  
  *Default*: `64`

- **-i, --input_path**  
  *Descrizione*: Percorso del file video di input.  
  *Default*: `testSet/videoBreve.mp4`

- **-o, --output_path**  
  *Descrizione*: Percorso dove salvare il file video "scramblato".  
  *Default*: `output_video.mp4`

### 3. Esempi d'uso

- **Esempio 1:** Eseguire lo script con i valori di default:
  ```
  python scramble.py
  ```

- **Esempio 2:** Utilizzare la modalità di `permutation` con un file di input e output specificati:
  ```
  python scramble.py -i percorso/del_video.mp4 -o percorso/video_scrambled.mp4
  ```
